SECURITY BULLETIN BOARD

Seven repeat offenders, one per department. Every incident report on file traces back to one of these. Approach with a packet capture, not your hands.

WANTED

The Con Artist

AKA: Phishing / Social Engineering

LAST SEEN: LAYER 07 — FRONT DESK
MO
Sends a request that looks completely legitimate and asks for something Front Desk shouldn't hand over.
Tools of the trade
Spoofed sender addresses, lookalike domains, pretext phone calls
Countermeasure
Security-awareness training; verify out-of-band before acting
THREAT LEVEL: NOVICE ●●○○○
REWARD: full credit on the incident report if you can explain why this one never shows up in a packet capture.
WANTED

The Eavesdropper

AKA: Packet Sniffing

LAST SEEN: LAYER 06 — TRANSLATION & WARDROBE
MO
Reads outgoing mail before it's sealed — only works if it was never sealed in the first place.
Tools of the trade
Wireshark, tcpdump on an unsecured segment
Countermeasure
Encrypt everything — TLS, SSH, VPN tunnels
THREAT LEVEL: NOVICE–INTERMEDIATE ●●●○○
REWARD: full credit for spotting the cleartext protocol in the capture before the professor does.
WANTED

The Impostor

AKA: Session Hijacking

LAST SEEN: LAYER 05 — SCHEDULING
MO
Steals an already-open meeting room instead of knocking — rides a session it never earned.
Tools of the trade
Stolen cookies/tokens, replay of captured session data
Countermeasure
Session timeouts, token rotation, re-auth on sensitive actions
THREAT LEVEL: INTERMEDIATE ●●●●○
REWARD: full credit for spotting a session token reused from an unexpected location.
WANTED

The Flood

AKA: DoS / DDoS

LAST SEEN: LAYER 04 — SHIPPING & RECEIVING
MO
Jams the loading dock with fake orders until real shipments can't get through.
Tools of the trade
Traffic generators, botnets
Countermeasure
Rate limiting, SYN cookies, upstream filtering
THREAT LEVEL: INTERMEDIATE ●●●○○
REWARD: full credit for finding the spike in half-open connections in netstat.
WANTED

The Forger

AKA: IP Spoofing

LAST SEEN: LAYER 03 — LOGISTICS
MO
Fakes the return address on a routing slip so the reply goes somewhere it shouldn't.
Tools of the trade
Crafted packets with a forged source address
Countermeasure
Ingress/egress filtering (BCP38), authenticated routing
THREAT LEVEL: INTERMEDIATE ●●●●○
REWARD: full credit for catching a source IP that doesn't match the expected subnet.
WANTED

The Impersonator

AKA: ARP Spoofing

LAST SEEN: LAYER 02 — LOCAL DISPATCH
MO
Hands out a fake address label so local traffic gets rerouted through the wrong desk.
Tools of the trade
ARP cache poisoning on the local segment
Countermeasure
Dynamic ARP Inspection, static ARP on critical hosts
THREAT LEVEL: INTERMEDIATE ●●●○○
REWARD: full credit for spotting two IPs claiming the same MAC in the ARP table.
WANTED

The Saboteur

AKA: Physical Tampering

LAST SEEN: LAYER 01 — INFRASTRUCTURE CREW
MO
Cuts the cable or jams the signal. Nobody upstairs even finds out there was a request.
Tools of the trade
Cable/patch panel access, an RF jammer
Countermeasure
Locked wiring closets, port security, cable audits
THREAT LEVEL: NOVICE ●●○○○
REWARD: full credit for finding the open/short before a laptop ever gets involved.

Cross-reference: each bulletin corresponds to the Incident Report filed in the matching department's case file (IR-01 through IR-07).

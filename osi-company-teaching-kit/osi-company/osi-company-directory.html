PERSONNEL DIRECTORY — 7 DEPARTMENTS

THE OSI COMPANY

Every request that leaves this building passes through all seven departments on the way out, and all seven again — in reverse — on the way back in. Most days nobody notices them. Some days, one of them has a very bad day. Case files below.

LAYER 07

Front Desk

Takes the request. The only department the customer ever sees.

OPERATIVE
PDU
Data
Signature protocols
HTTP/S, DNS, SMTP, FTP, DHCP
On the range
Every browser tab, curl request, and DNS lookup on the student stations starts here
INCIDENT REPORT IR-07

The Con Artist — a request that looks completely legitimate, asking Front Desk to hand over something it normally wouldn't.

Tell: no packet capture catches this one — it's caught by a human asking "why is IT emailing me about my password?"

LAYER 06

Translation & Wardrobe

Encrypts, compresses, and reformats everything on the way out — and reverses all of it coming in.

OPERATIVE
PDU
Data
Signature protocols
TLS/SSL, JPEG/MPEG, ASCII/Unicode
On the range
The layer doing the work when Wireshark shows a TLS handshake instead of readable HTTP
INCIDENT REPORT IR-06

The Eavesdropper — reads outgoing mail before it's sealed, because it was never sealed in the first place.

Tell: cleartext HTTP or Telnet showing up where you expected TLS or SSH.

LAYER 05

Scheduling

Books the meeting room and keeps it held open for the whole conversation.

OPERATIVE
PDU
Data
Signature protocols
NetBIOS, RPC, PPTP, SIP, sockets
On the range
The socket that stays open for an entire SSH session — kill the session, kill the socket
INCIDENT REPORT IR-05

The Impostor — steals an already-open meeting room instead of knocking, riding a session it never earned.

Tell: a session cookie or token reused from an unexpected IP or location.

LAYER 04

Shipping & Receiving

Splits the order into labeled boxes and decides how carefully to track each one.

OPERATIVE
PDU
Segment (TCP) / Datagram (UDP)
Signature protocols
TCP — Certified Mail Clerk · UDP — Bike Courier
On the range
Port numbers — the ones you'll be scanning with Nmap all semester — live here
INCIDENT REPORT IR-04

The Flood — jams the loading dock with fake orders until real shipments can't get through.

Tell: SYN floods with no completed handshake, or a spike in half-open connections.

LAYER 03

Logistics

Picks the route across town for every shipment.

OPERATIVE
PDU
Packet
Signature protocols
IP, ICMP, OSPF, BGP
On the range
Your C8200 routers — this is their entire job description
INCIDENT REPORT IR-03

The Forger — fakes the return address on a routing slip so the reply goes somewhere it shouldn't.

Tell: a source IP that doesn't match the expected subnet in a traceroute.

LAYER 02

Local Dispatch

Knows every address on this block by heart. Hands the truck to the next truck.

OPERATIVE
PDU
Frame
Signature protocols
Ethernet, ARP, PPP
On the range
Your C1000 switches — and the layer every ARP table lives on
INCIDENT REPORT IR-02

The Impersonator — hands out a fake address label so local traffic gets rerouted through the wrong desk.

Tell: two IPs claiming the same MAC address in the ARP table.

LAYER 01

Infrastructure Crew

Doesn't read anything. Is the road everything else drives on.

OPERATIVE
PDU
Bits
Signature protocols
Ethernet cabling, fiber, radio, NICs, hubs
On the range
Every blinking link light on the rack, every patch cable re-seated at 2am
INCIDENT REPORT IR-01

The Saboteur — cuts the cable or jams the signal. Nobody upstairs even finds out there was a request.

Tell: link light's out, or a cable tester shows an open/short before a laptop ever gets involved.

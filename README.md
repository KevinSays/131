# IT131 – CCNA: Introduction to Networks

Student-facing session review pages for IT131: lecture recaps, flashcards, sample quizzes, worked examples, and glossaries for each session, plus the "OSI Company" teaching kit referenced throughout and a growing page of reference graphics and diagrams.

**Site:** start at `index.html` — it links out to every session and reference page.

Built with plain HTML/CSS/JS, no build step. To preview locally, just open `index.html` in a browser, or serve the folder with any static file server.
